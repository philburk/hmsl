# Downloading and Installing HMSL

1. Download the latest HMSL_{version}.dmg from the [releases page](https://github.com/philburk/hmsl/releases).
1. Double click the .dmg file to open it.
1. Drag HMSL.app to the Applications folder.
1. Launch HMSL from the Applications folder.
1. The first time you run HMSL it will ask for a work folder. We suggest "Documents/HMSL".
   HMSL will copy its pieces, tools and other Forth source files into that folder.
   You can edit these files. HMSL will not overwrite them when you install a new version.
1. If macOS asks whether HMSL can access your Documents folder, click Allow.
1. Hit 'y' key to initialize HMSL.
1. Wait a few seconds then hit the ENTER key.

HMSL will now be ready for use.

To choose a different work folder, hold down the Option key while launching HMSL.

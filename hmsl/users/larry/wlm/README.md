# Worlds Longest Melody by Larry Polansky.

See the old [PDF](twlm.pdf) for more information.
This uses MIDI instruments.

## To Run

Launch HMSL then enter:

    include users/assigns.fth
    include wlm:wlm_load.fth
    do.wlm

## To Play

1. Expand the screen so you can seel the control grids.
2. Click the "Play" button at the middle left of the screen.
3. Wait several seconds. It starts slowly.
4. See the [PDF](twlm.pdf) for an explanation of the controls.

Close the window when done.

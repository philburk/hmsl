# Horn by Larry Polansky.

This piece requires a Yamaha FB-01 because it
uses SysEx for fractional pitch.

## To Run

Connect a Yamaha FB-01

Launch HMSL then enter:

    include users/assigns.fth
    include horn:load_horn.fth
    horn

## To Play

This was meant to be accompanied by a French Horn.

Place your own HMSL pieces and Forth files in this "mystuff" folder.

Files that you create in this folder will not be overwritten when you
install a new version of HMSL.

Avoid modifying the standard HMSL files in "fth", "pieces", "users",
"amiga", "screens", or "tools" directly, as those folders are updated
when new versions of HMSL are installed. Instead, copy any example pieces
you wish to modify into "mystuff" first.
